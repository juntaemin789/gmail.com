# 쉼표 , — 걸어 다니며 수다 떠는 3D 광장

쉬는 시간이나 남는 시간에 들르는 3D 커뮤니티입니다. 사람 모양 아바타를 만들어 광장을 걸어 다니다가 건물 문으로 들어가면 그 방으로 이동하고, 같은 방 사람들과 말풍선으로 이야기합니다.

## 기능

- **회원가입 없이 입장**: 닉네임을 정하고 아바타(피부 5, 머리 모양 6, 머리 색 6, 상의 8, 하의 6가지)를 고르면 끝. 다음에 와도 기억됩니다.
- **3D 공간**: 가구, 조명, 그림자가 있는 공간을 3인칭 시점으로 걸어 다닙니다. 가구와 벽은 통과할 수 없습니다.
- **광장과 방 6개**: 광장의 건물 문으로 걸어 들어가면 방으로 이동합니다. 방 목록에서 바로 이동할 수도 있습니다.
- **방별 실시간 채팅**: 말하면 아바타 머리 위에 말풍선이 뜨고 채팅창에도 남습니다. 같은 방 사람에게만 보입니다.
- **방마다 다른 주제**: 방마다 대상과 분위기가 다르고, "오늘의 이야깃거리"가 매일 자정(한국 시간)에 바뀝니다.
- **조작**: 화면을 누르면 그곳으로 걸어가고, 드래그하면 시점이 돌아갑니다. 두 손가락이나 마우스 휠로 확대·축소합니다. PC에서는 방향키나 WASD로도 걷습니다.
- **기본 안전장치**: 도배 방지, 욕설 가림, 다른 사람 채팅 숨기기, 신고 기록.

| 공간 | 누구를 위한 곳 | 모습 |
|---|---|---|
| 광장 | 모두 | 분수, 벤치, 가로수가 있는 낮의 광장. 건물 6채 |
| 카페 쉼표 | 직장인 | 원목 바닥, 카운터와 바리스타, 테이블 좌석 |
| 고민 라운지 | 연애·고민 상담 | 벽난로, 소파, 스탠드 조명 |
| PC방 | 게이머 | 네온 조명, PC 좌석, 오락기 |
| 포장마차 | 먹는 게 낙인 사람 | 주방, 플라스틱 테이블, 줄 전구 |
| 스터디룸 | 대학생·취준생 | 책장, 긴 책상, 화이트보드 |
| 루프탑 | 돈 모으는 사람 | 밤의 옥상, 야경, 빈백 |

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm start      # http://localhost:3000
npm test       # 자동 테스트
```

브라우저 창을 두 개 열어 접속하면 서로의 아바타가 보입니다.

### 서버 없이 미리 보기

저장소의 `preview.html` 파일 하나를 브라우저로 열면 서버 없이 바로 둘러볼 수 있습니다. 인터넷 연결도 필요 없습니다. 혼자 둘러보는 미리보기 모드라서 다른 사람은 보이지 않고, 분위기를 보여 주는 "예시 손님" 두 명만 돌아다닙니다.

코드를 고친 뒤에는 `npm run build:html`로 이 파일을 다시 만듭니다.

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DB_PATH` | `data/swimpyo.db` | 신고 기록 데이터 파일. Railway 볼륨이 있으면 자동으로 볼륨 안에 저장 |

## 방 바꾸기

- **이름·대상·이야깃거리**: `src/rooms.js`에서 각 방의 `name`, `group`, `desc`, `topics`를 고칩니다. 이야깃거리는 목록을 하루에 하나씩 돌아가며 보여 주고, 지금은 방마다 6개씩 들어 있습니다.
- **생김새(가구·조명·색)**: `public/scenes.js`의 `SCENES`에서 방마다 가구를 놓는 코드를 고칩니다. 예를 들어 `b.sofa(x, z, 방향, 너비, 색)` 한 줄이 소파 하나입니다.
- **방 추가**: `src/rooms.js`의 `ROOMS`에 방을 넣고 광장 `portals`에 문 위치를 추가한 뒤, `public/scenes.js`에 같은 id로 공간을 만들고 광장에 건물을 하나 세웁니다.

## 인터넷에 올리기

저장소에 Railway용 설정 파일(`railway.json`)이 들어 있습니다.

1. [railway.com](https://railway.com)에 GitHub 계정으로 로그인합니다.
2. **New Project → Deploy from GitHub repo**를 누르고 이 저장소를 선택합니다.
3. 서비스의 **Settings → Networking → Generate Domain**을 누르면 `https://....up.railway.app` 주소가 생깁니다.
4. 서비스를 우클릭해 **Attach Volume**을 누르고 Mount path에 `/data`를 입력합니다. 볼륨이 없으면 배포할 때마다 신고 기록이 지워집니다.

실시간 연결(웹소켓)을 쓰기 때문에 서버가 계속 켜져 있는 호스팅이 필요합니다. GitHub Pages 같은 정적 호스팅에는 올릴 수 없습니다. 서버 한 대로 동작하도록 만들어져 있어서, 서버를 여러 대로 늘리려면 구조를 바꿔야 합니다. 지금 설정된 한도는 방 하나에 40명, 전체 600명입니다(`src/realtime.js`의 `LIMITS`).

## 구조

```
server.js            웹 서버, 익명 식별 쿠키
src/rooms.js         방 이름·대상·이야깃거리·문 위치
src/realtime.js      실시간 처리 (입장, 이동, 채팅, 신고)
src/db.js            SQLite 테이블 (신고)
public/index.html    화면 뼈대
public/app.js        화면 동작 (카메라, 이동, 이름표·말풍선, 채팅)
public/scenes.js     공간 만들기 (바닥·벽·가구·조명)
public/avatar.js     아바타 만들기와 걷는 동작
public/style.css     디자인
scripts/build-html.js  preview.html 만들기
preview.html         서버 없이 여는 미리보기 (자동 생성)
tests/               자동 테스트
```

3D 그리기는 [three.js](https://threejs.org)를 사용합니다. 가구, 건물, 아바타는 외부 3D 모델 파일 없이 코드로 직접 조립했습니다.

## 아직 없는 것

- **사진 같은 사실감**: 모든 것을 기본 도형으로 조립했기 때문에 게임 수준의 정교한 모델은 아닙니다. 더 사실적으로 만들려면 전문 3D 모델(GLB 파일)을 구해서 넣어야 합니다.
- **의자에 앉기, 감정 표현, 음성 대화**
- **운영자 화면**: 신고는 DB의 `reports` 테이블에 쌓이기만 합니다.
- **이야깃거리 자동 생성**: `src/rooms.js`에 직접 적어야 합니다.
- **이용약관·개인정보처리방침**: 광고를 붙이거나 정식으로 공개하기 전에 필요합니다.
- **낮은 사양 기기 대응**: 오래된 휴대폰에서는 느릴 수 있습니다. 실제 기기에서의 속도는 확인하지 못했습니다.

## 수익 모델 (아직 구현되지 않음)

방 목록 창에 광고 자리(`광고 영역`)만 잡아 두었습니다. 사람이 모인 뒤 붙일 수 있는 방법:

- **광고**: 방 목록, 방 입장 사이 화면
- **브랜드 공간**: 기업이 돈을 내고 광장에 자기 건물을 세우거나, 방 안 포스터·간판 자리를 삽니다.
- **아바타 꾸미기 아이템**: 유료 의상·머리 모양·말풍선 스킨
