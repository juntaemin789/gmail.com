# 쉼표 , — 걸어 다니며 투표하는 찬반 광장

쉬는 시간이나 남는 시간에 들르는 커뮤니티입니다. 캐릭터를 만들어 광장을 돌아다니다가 마음에 드는 방에 들어가고, 방 바닥의 **A/B 구역 중 서 있는 쪽이 내 한 표**가 됩니다. 같은 방 사람들과 말풍선으로 수다를 떱니다.

## 기능

- **회원가입 없이 입장**: 닉네임을 정하고 캐릭터(색깔 8가지, 표정 4가지, 꾸미기 6가지)를 고르면 끝. 다음에 와도 기억됩니다.
- **광장과 테마 방 6개**: 광장에서 문으로 걸어 들어가면 방으로 이동합니다. 방 목록에서 바로 이동할 수도 있습니다.
- **걸어가서 투표**: 방마다 오늘의 질문이 하나 있고, 바닥의 A 구역이나 B 구역에 서면 투표됩니다. 반대쪽으로 가면 표가 바뀝니다. 투표해야 결과(%)가 보입니다.
- **방별 실시간 채팅**: 말하면 캐릭터 머리 위에 말풍선이 뜨고, 아래 채팅창에도 남습니다. 같은 방 사람에게만 보입니다.
- **이동**: 화면을 누르면 그곳으로 걸어갑니다. PC에서는 방향키나 WASD도 됩니다.
- **질문은 매일 자정(한국 시간)에 교체**, 한 사람은 방마다 하루 한 표.
- **기본 안전장치**: 도배 방지, 욕설 가림, 다른 사람 채팅 숨기기, 신고 기록.

| 방 | 누구를 위한 방 | 분위기 |
|---|---|---|
| ☕ 탕비실 | 직장인 | 사무실 휴게 공간 |
| 💌 연애상담소 | 연애·썸 고민러 | 분홍빛 상담실 |
| 🕹️ 오락실 | 게이머 | 어두운 네온 오락실 |
| 🍜 야식당 | 먹는 게 낙인 사람 | 따뜻한 포장마차 |
| 🎸 동아리방 | 대학생·취준생 | 파란 동아리방 |
| 🌙 머니 옥상 | 돈 모으는 사람 | 밤의 옥상 |

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm start      # http://localhost:3000
npm test       # 자동 테스트
```

브라우저 창을 두 개 열어 접속하면 서로의 캐릭터가 보입니다.

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DB_PATH` | `data/swimpyo.db` | 투표·신고 데이터 파일. Railway 볼륨이 있으면 자동으로 볼륨 안에 저장 |

## 방과 질문 바꾸기

`src/rooms.js` 파일 하나에 모든 방이 정의되어 있습니다.

- **질문 추가**: 각 방의 `questions` 목록에 `{ q: '질문', a: 'A 선택지', b: 'B 선택지' }`를 추가합니다. 목록을 하루에 하나씩 돌아가며 사용하므로, 질문이 많을수록 같은 질문이 덜 반복됩니다. 지금은 방마다 6개씩 들어 있습니다.
- **방 추가**: `ROOMS`에 방을 하나 더 넣고, 광장(`plaza`)의 `portals`에 문 위치를 추가합니다.

## 인터넷에 올리기

저장소에 Railway용 설정 파일(`railway.json`)이 들어 있습니다.

1. [railway.com](https://railway.com)에 GitHub 계정으로 로그인합니다.
2. **New Project → Deploy from GitHub repo**를 누르고 이 저장소를 선택합니다.
3. 서비스의 **Settings → Networking → Generate Domain**을 누르면 `https://....up.railway.app` 주소가 생깁니다.
4. 서비스를 우클릭해 **Attach Volume**을 누르고 Mount path에 `/data`를 입력합니다. 볼륨이 없으면 배포할 때마다 투표 기록이 지워집니다.

실시간 연결(웹소켓)을 쓰기 때문에 서버가 계속 켜져 있는 호스팅이 필요합니다. GitHub Pages 같은 정적 호스팅에는 올릴 수 없습니다. 서버 한 대로 동작하도록 만들어져 있어서, 서버를 여러 대로 늘리려면 구조를 바꿔야 합니다. 지금 설정된 한도는 방 하나에 40명, 전체 600명입니다(`src/realtime.js`의 `LIMITS`).

## 구조

```
server.js            웹 서버, 익명 식별 쿠키
src/rooms.js         방·테마·질문 정의
src/realtime.js      실시간 처리 (입장, 이동, 투표, 채팅, 신고)
src/db.js            SQLite 테이블 (투표, 신고)
public/index.html    화면 뼈대
public/app.js        화면 동작 (방 그리기, 이동, 말풍선, 투표 버튼)
public/character.js  캐릭터 그리기
public/style.css     디자인
tests/               자동 테스트
```

## 아직 없는 것

- **운영자 화면**: 신고는 DB의 `reports` 테이블에 쌓이기만 합니다. 확인하고 제재하는 화면이 없습니다.
- **강한 중복 투표 방지**: 브라우저 쿠키로 한 사람을 구분하므로, 쿠키를 지우면 다시 투표할 수 있습니다.
- **질문 자동 생성·사용자 질문 제안**: 질문은 `src/rooms.js`에 직접 적어야 합니다.
- **지난 질문 결과 보기, 알림, 친구 기능**
- **이용약관·개인정보처리방침**: 광고를 붙이거나 정식으로 공개하기 전에 필요합니다.

## 수익 모델 (아직 구현되지 않음)

방 목록 창에 광고 자리(`광고 영역`)만 잡아 두었습니다. 사람이 모인 뒤 붙일 수 있는 방법:

- **광고**: 방 목록, 방 입장 사이 화면
- **브랜드 방·스폰서 질문**: 기업이 돈을 내고 자기 테마의 방을 열거나 질문을 올립니다. 투표 결과가 곧 설문 데이터입니다.
- **캐릭터 꾸미기 아이템**: 유료 모자·의상·말풍선 스킨
