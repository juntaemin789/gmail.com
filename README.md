# 💰 머니계산기

연봉 실수령액, 대출 이자, 퇴직금을 계산하는 무료 웹사이트입니다. 검색으로 들어온 방문자에게 **광고(Google AdSense)** 를 보여주는 방식으로 수익을 냅니다.

- 서버 없이 HTML/CSS/JS만으로 동작해서 **호스팅비 0원**
- 입력값은 브라우저 안에서만 계산하고 어디에도 저장하지 않음
- 모바일과 다크모드 지원

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 메인 페이지 |
| `salary/` | 연봉 실수령액 계산기 (2026년 요율) |
| `loan/` | 대출 이자 계산기 (원리금균등·원금균등·만기일시) |
| `severance/` | 퇴직금 계산기 |
| `privacy/` | 개인정보처리방침 (애드센스 심사에 필요) |
| `assets/calc.js` | 계산 로직. **요율은 매년 이 파일 상단 `RATES`에서 수정** |
| `tests/calc.test.js` | 계산 테스트 (`node tests/calc.test.js`) |

## 내 컴퓨터에서 보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 수익화 순서

1. **무료로 공개하기 (GitHub Pages)**: 저장소 Settings → Pages → Branch를 이 브랜치(또는 main)로 지정하고 저장하면 몇 분 뒤 주소가 생깁니다.
2. **도메인 연결 (권장, 연 1~2만 원)**: 애드센스 승인과 검색 노출에 유리합니다. 연결 후 `sitemap.xml`과 `robots.txt`의 `https://example.com`을 실제 주소로 바꾸세요.
3. **검색엔진 등록**: [구글 서치 콘솔](https://search.google.com/search-console)과 [네이버 서치어드바이저](https://searchadvisor.naver.com)에 사이트를 등록하고 sitemap.xml을 제출합니다.
4. **애드센스 신청**: [Google AdSense](https://adsense.google.com)에 가입하고, 승인되면
   - 각 HTML `<head>`의 주석 처리된 애드센스 스크립트를 풀고 `ca-pub-` 번호를 넣습니다.
   - `광고 영역` 자리(`<div class="ad-slot">`)를 애드센스 광고 코드로 바꿉니다.
   - `ads.txt` 파일을 만들어 애드센스가 알려주는 한 줄을 넣습니다.
5. **방문자 늘리기**: 계산기를 하나씩 추가하세요. 페이지가 많을수록 검색 유입이 늘어납니다.
   - 추천 추가 아이디어: 시급·주휴수당, 전월세 전환, 적금 이자, 양도소득세, 부가세, 실업급여, BMI, 나이·D-day

## 주의

계산 결과는 추정치입니다. 특히 소득세는 국세청 간이세액표가 아니라 연간 세액을 추정해 12로 나눈 값이라 실제 원천징수액과 조금 다를 수 있습니다. 매년 1월 4대보험 요율과 세법 개정 내용을 확인해 `assets/calc.js`의 `RATES`를 고쳐 주세요.
