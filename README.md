# 🛠 일감 — 인력사무소 없는 일용직 직거래

인력사무소를 거치지 않고 **일할 사람을 구하는 쪽(구인자)** 과 **일자리를 찾는 쪽(구직자)** 이 직접 만나는 웹사이트입니다.

## 인력사무소가 하던 일을 이렇게 대신합니다

| 인력사무소 | 일감 |
|---|---|
| 새벽에 사무소에 나가 대기 | 전날 휴대폰으로 공고를 보고 지원 |
| 일당의 약 10%를 소개비로 뗌 | 소개 수수료 없음 |
| 소장이 사람을 골라 보냄 | 구인자가 지원자의 후기·경력·안전교육 이수 여부를 보고 직접 채용 확정 |
| 어떤 현장·어떤 사람인지 가 봐야 앎 | 서로 남긴 별점과 후기가 쌓임 |

## 기능

- 휴대폰 번호로 회원가입 (구인자 / 구직자)
- 구인자: 공고 등록(직종·지역·근무일·시간·일당·인원·지급 방식), 지원자 확인, 채용 확정·거절, 공고 마감
- 구직자: 지역·직종으로 일자리 검색, 지원·취소, 내 지원 내역
- **전화번호와 상세 주소는 채용이 확정된 상대방에게만 공개**
- 정원이 차면 자동으로 모집완료, 확정자가 취소하면 다시 모집중
- 최저임금보다 낮은 일당은 등록 불가
- 근무일 이후 서로 별점·후기 1회씩 (공개 프로필에 이름은 `김*수`처럼 가려서 표시)

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run seed   # (선택) 화면 확인용 예시 데이터. 계정 비밀번호는 모두 test1234
npm start      # http://localhost:3000
npm test       # 자동 테스트
```

예시 계정: 구인자 `01011110001`, 구직자 `01022220001`

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DB_PATH` | `data/ilgam.db` | SQLite 데이터 파일 위치. Railway 볼륨이 있으면 자동으로 볼륨 안에 저장 |

## 인터넷에 올리기

이 사이트는 서버와 데이터 파일이 필요해서 GitHub Pages에는 올릴 수 없습니다. 저장소에 Railway용 설정 파일(`railway.json`)이 들어 있습니다.

1. [railway.com](https://railway.com)에 GitHub 계정으로 로그인합니다.
2. **New Project → Deploy from GitHub repo**를 누르고 이 저장소를 선택합니다. 자동으로 빌드와 배포가 시작됩니다.
3. 만들어진 서비스를 눌러 **Settings → Networking → Generate Domain**을 누르면 `https://....up.railway.app` 주소가 생깁니다.
4. **데이터 유지 설정 (중요)**: 프로젝트 화면에서 서비스를 우클릭해 **Attach Volume**을 누르고 Mount path에 `/data`를 입력합니다. 볼륨을 붙이지 않으면 배포할 때마다 회원과 공고 데이터가 지워집니다. 볼륨을 붙이면 서버가 자동으로 그 안에 데이터를 저장합니다.

Railway는 체험 크레딧을 다 쓰면 유료입니다. 요금은 Railway 가격 페이지에서 확인하세요.

Render, Fly.io, 일반 VPS 등 디스크가 유지되는 다른 Node.js 호스팅도 쓸 수 있습니다. `DB_PATH` 환경 변수를 그 디스크 안의 파일 경로로 지정하고, 반드시 HTTPS로 서비스하세요.

## 구조

```
server.js        라우트 (가입·로그인·공고·지원·후기)
src/db.js        SQLite 테이블 정의
src/views.js     화면 HTML
src/util.js      최저시급, 지역·직종 목록, 공통 함수
src/seed.js      예시 데이터
public/style.css 디자인
tests/           자동 테스트
```

매년 1월 `src/util.js`의 `MIN_HOURLY_WAGE`(최저시급)를 새 금액으로 바꿔 주세요.

## 실제 운영 전에 꼭 필요한 것

지금은 핵심 흐름이 동작하는 첫 버전입니다. 실제로 사람을 받기 전에 아래가 필요합니다.

1. **법적 신고·등록 확인** — 구인 공고를 올려 주는 사이트는 직업안정법상 **직업정보제공사업 신고**가, 사람을 소개하고 수수료를 받으면 **유료직업소개사업 등록**이 필요할 수 있습니다. 시작 전에 관할 고용센터(고용노동부)나 노무사에게 확인하세요.
2. **휴대폰 본인인증** — 지금은 번호가 실제 본인 것인지 확인하지 않습니다. 문자 인증(예: NHN Cloud, 알리고)이나 본인인증(PASS)을 붙여야 허위 가입을 막을 수 있습니다.
3. **이용약관·개인정보처리방침** — 가입 화면에 동의 체크는 있지만 약관 문서는 아직 없습니다.
4. **비밀번호 찾기, 신고·차단, 관리자 화면** — 아직 없습니다.
5. **알림** — 지원·채용 확정 시 문자나 카카오 알림톡이 없으면 사용자가 직접 접속해 확인해야 합니다.

## 수익 모델 (아직 구현되지 않음)

결제 기능은 들어 있지 않습니다. 사용자가 모인 뒤 붙일 수 있는 방법:

- **급구 공고 상단 노출** — 건당 3,000~10,000원
- **구인자 월 정액제** — 공고를 자주 올리는 업체 대상
- **매칭 수수료** — 인력사무소(약 10%)보다 훨씬 낮게. 단, 위 1번의 유료직업소개사업 등록 대상입니다.
- **부가 서비스** — 일용직 근로계약서·노임 명세서 자동 작성, 산재·상해보험 연계
